# IA_Proyecto

## Función
Esta carpeta agrupa los artefactos de soporte del proyecto: datos de trabajo, metadatos, notebooks, logs y utilidades auxiliares.

## Estructura principal
- `data/`: archivos raw, processed y metadata de trazabilidad.
- `logs/`: salida de ejecución y seguimiento.
- `notebooks/`: notebooks de apoyo y demostración.
- `src/`: utilidades compartidas del proyecto.

## Uso
Esta carpeta no reemplaza al pipeline principal. Sirve como contenedor de apoyo para materiales, salidas y trazabilidad del caso fintech.
